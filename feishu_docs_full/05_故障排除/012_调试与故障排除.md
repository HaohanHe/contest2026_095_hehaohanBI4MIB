## 调试与故障排除

### 常用调试方法

#### 1. 串口调试

1. 安装 [mobaxterm](https://mobaxterm.mobatek.net/) 软件
2. 使用 usb 转 ttl 串口板连接开发板 uart2 接口，速率选择 **1500000**

#### 2. adb 调试

**日志打印**

```
adb logcat
```

**命令行**

```
adb shell
```

### Q3: 烧录失败处理

连接串口2，再尝试。

### Q4: 程序代码逻辑无问题，但是运行崩溃

默认的 stacksize 比较小，通过 menuconfig 调整程序的 stacksize。

先通过以下命令进入 menuconfig：

```bash
./build.sh vendor/allwinnertech/boards/r528/r528s3-gemini-s1/configs/nsh menuconfig
```

以下通过以调整 led_rgb 程序的 stacksize 作为参考。
