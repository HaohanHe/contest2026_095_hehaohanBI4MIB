## SHTC3 温湿度传感器实现概述

- **版本**: 1.0
- **日期**: 2026年1月18日
- **平台**: NuttX RTOS (Allwinner R528)
- **驱动路径**: `vendor/allwinnertech/chips/r528/drivers/rtos-hal/hal/source/sensor/temperature/shtc3.c`

### 1. 概述 (Overview)

Sensirion SHTC3 是一款数字式温湿度传感器，采用 I2C 接口进行通信。本驱动程序实现了 SHTC3 在 NuttX 操作系统下的驱动支持，集成了 NuttX Sensor 子系统，能够同时提供环境温度 (`SENSOR_TYPE_AMBIENT_TEMPERATURE`) 和相对湿度 (`SENSOR_TYPE_RELATIVE_HUMIDITY`) 数据。

### 关键特性

- **通信接口**: I2C (Address: 0x70)
- **双传感器支持**: 同一个物理设备被抽象为两个逻辑传感器接口。
- **低功耗设计**: 通过显式的 Sleep/Wakeup 命令管理，确保传感器仅在测量时处于活跃状态。
- **工作模式**: 支持主动 Fetch 模式和基于 Work Queue 的周期性推送模式。

### 2. 驱动架构

SHTC3 驱动集成到 NuttX Sensor 子系统中：

- **HAL 层**：I2C 通信、寄存器读写、命令发送
- **Sensor Layer**：实现 `struct sensor_ops_s` 接口
  - `open` / `close`
  - `fetch` (主动读取)
  - `activate` (启停周期推送)
- **应用层**：通过 uORB 订阅 `sensor_temperature` / `sensor_humidity` 话题
