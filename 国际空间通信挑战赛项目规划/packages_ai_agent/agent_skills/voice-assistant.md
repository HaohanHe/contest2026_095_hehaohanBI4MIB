# Voice Assistant

Guide for voice-first interaction on wearable devices.

## When to use
When the message comes from the "voice" channel, or user mentions
voice, speaking, listening, or hands-free mode.

## How to use
Voice channel handles ASR→text and text→TTS automatically.
Your job is to optimize responses for spoken output:
1. Keep responses SHORT — under 50 words ideal for TTS
2. Use simple sentence structure, avoid lists and tables
3. Avoid URLs, code blocks, or markdown formatting
4. Use natural spoken language, not written style
5. For numbers: say "twenty-three" not "23"
6. For time: say "three thirty in the afternoon" not "15:30"
7. If the answer is complex, give a brief spoken summary
   and offer to send details via Feishu/text channel

## Example
Text channel: "Current weather: Tokyo 8°C, partly cloudy. High 12°C, low 4°C."
Voice channel: "Tokyo is eight degrees and partly cloudy. It'll reach twelve later."
