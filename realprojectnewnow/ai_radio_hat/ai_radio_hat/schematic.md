## 1. 电台音频输入到 R528 LINEIN

电台 SPK 输出（耳机口）→ R528 LINEIN（给 ASR 用）：

```
        电台耳机座 J1
        ┌───────────┐
   SPK+ │  Tip/Ring │────────┬──── 10µF(C1) ────┬──── 10k(R1) ──┬──→ LINEIN_L
        │           │        │                   │               │
   SPK- │  Sleeve   │────────┴───────────────────┴──── 10k(R2) ──┴──→ GND
        └───────────┘                            │
                                              100k(RV1)
                                              音量电位器
                                              (另一端接地)
```

### 说明
- J1 使用 4段耳机座：Tip = SPK_L，Ring1 = SPK_R，Ring2 = MIC+，Sleeve = GND。
- 电台 SPK 信号经过 C1 隔直、RV1 分压衰减后送入 R528 LINEIN。
- R528 LINEIN 通常可接受最大约 1Vrms 的输入，手台耳机输出可达 2Vpp 以上，必须用电位器衰减。
- 如果只需要单声道，SPK_R 可悬空或同样经电阻接地。

## 2. R528 HPOUT 到电台 MIC 输入

R528 HPOUT → 电台 MIC 输入（用于 TTS/数字语音通联）：

```
        R528 HPOUT
   HPOUT_L ──── 10µF(C2) ────┬──── 1k(R3) ────┬──→ J1 MIC+
                             │                │
   HPOUT_GND ────────────────┴──── 10k(R4) ───┴──→ J1 GND
                             │
                          10k(RV2)
                          输出电位器
                          (另一端接地)
```

### 说明
- 电台 MIC 口自带偏置电压（约 2V），我们只需要电容耦合 + 限流电阻。
- RV2 用于调节输出电平，防止 R528 HPOUT 过载电台 MIC。
- 如果不需要向电台发语音，这部分可以不贴器件。

## 3. 音频隔离变压器方案（推荐，替代上面直接阻容）

更稳的接法是用 600:600 音频变压器实现地隔离：

```
电台 SPK+ ── C1(10µF) ── R8(100Ω) ──┬── T1 初级 ──┬──→ 电台 SPK-
                                     │             │
                                     │    600:600  │
                                     │    变压器    │
                                     │             │
R528 LINEIN_L ←── RV1 ──────────────┴── T1 次级 ──┴──→ R528 GND
```

次级同样用电阻分压把电平降到 LINEIN 范围。这样可以避免电台和 R528 的地环路噪声。

## 4. PTT 控制电路

R528 GPADC0 → 光耦隔离 → MOS 开关 → 电台 PTT：

```
R528 GPADC0 ── R7(330Ω) ──┬──┬── U1(PC817) LED+
                          │  │
                         C5  │            U1 输出侧
                    (100nF)  │            ┌──────┐
                          │  │        C/E │      │
                         GND GND        ├─│  U1  │─┤
                                         │ │      │ │
                                         │ └──────┘ │
                                         │          │
                                         │   R5 1k  │
                                         └──/\/\──┴──┬── Q1(2N7002) G
                                                       │
                                                       │  Q1
                                                       │
                                      J4 PTT+  ←───────┼── Q1 D
                                                       │
                                      J4 PTT-  ←───────┴── Q1 S ── GND
```

### 说明
- GPADC0 设置为 GPIO 输出，高电平 = 发射。
- PC817 输出驱动 2N7002 栅极，D-S 并联到电台 PTT 按键两端。
- 电台 PTT 一般是对地短接触发，所以 Q1 的 D/S 跨接在 PTT+/PTT- 上即可。
- D1 反向并联在 PTT 两端，防止电台内部感性负载反向击穿 Q1。

## 5. CAT 串口电路

R528 底部 R_TX/R_RX ↔ 电台 CAT：

```
R528 R_TX ── C9(22pF) ──┬── R10(100Ω) ──┬── J2 CAT-TX
                        │               │
                        │               └── U2 TXS0102 A1
                        │                   │
R528 R_RX ── C10(22pF)──┼── R11(100Ω) ────┼── J2 CAT-RX
                        │                   │
                       GND                  │
                                            │
                    3.3V ──────────────────┼── U2 VCCA
                    5V  ───────────────────┼── U2 VCCB (如果电台是 5V TTL)
                    GND ───────────────────┴── U2 GND
```

### 说明
- U2 TXS0102 是可选的。如果确认电台 CAT 是 3.3V TTL，可以直接把 R_TX/R_RX 经 100Ω 电阻接到 J2。
- 大多数业余电台（泉盛、宝峰、八重洲部分型号）的 CAT 口是 3.3V 或 5V TTL，不是 RS-232。
- C9/C10 是串口信号完整性用的小电容，可贴可不贴。

## 6. I2C 扩展接口

```
R528 PB9 (TWI2_SDA) ──── J3 SDA
R528 PB8 (TWI2_SCK) ──── J3 SCL
R528 3.3V ───────────── J3 VCC
R528 GND ────────────── J3 GND
```

接上拉电阻 R1/R2（10kΩ）到 3.3V。

Gemini-S1 3.3V ──── R12(10Ω) ──── LED1(0805 红) ──── GND
