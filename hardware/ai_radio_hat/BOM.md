> 版本：v1.0
> 板尺寸：80mm × 50mm，2层板，1.6mm 厚度
> 设计目标：通过 2.54mm 排针/杜邦线连接 Gemini-S1，提供电台音频、PTT、CAT、I2C 扩展接口

## 说明

- J1 耳机座用于同时连接电台的 SPK（输入到 R528）和 MIC（输出到电台）。
- U2 TXS0102 为可选器件：如果确认电台 CAT 是 3.3V TTL，可直接用 R_TX/R_RX 直连，不贴 U2。
- RV1/RV2 用于调节输入/输出音频电平，避免过载。
- 5V 输入仅当外接大功率运放/电台 MIC 偏置需要时使用；一般情况下 Gemini-S1 可通过排针供电。

## 连接 Gemini-S1 需要的杜邦线

| 扩展板端 | Gemini-S1 端 | 说明 |
|---|---|---|
| J2 CAT-TX | R_TX（底部排针） | 电台 CAT 串口发送 |
| J2 CAT-RX | R_RX（底部排针） | 电台 CAT 串口接收 |
| J2 CAT-GND | GND | 共地 |
| J2 CAT-VCC | 3.3V | 给电平转换供电 |
| PTT_IN | GPADC0（右侧排针） | PTT 控制 GPIO |
| PTT_GND | GND | 共地 |
| LINEIN_L | LINEIN（顶部粉色接口） | R528 音频输入 |
| LINEIN_GND | LINEIN_GND | 音频地 |
| HPOUT_L | HPOUT（顶部绿色接口） | R528 音频输出 |
| HPOUT_GND | HPOUT_GND | 音频地 |
| J3 SDA | TWI2_SDA (PB9) | I2C 数据 |
| J3 SCL | TWI2_SCK (PB8) | I2C 时钟 |
| J3 3V3 | 3.3V | 传感器供电 |
| J3 GND | GND | 共地 |
