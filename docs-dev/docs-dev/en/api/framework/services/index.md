# Services API

The Services module provides core application management services for the openvela system, including Activity Manager Service (AMS) and Package Manager Service (PMS), responsible for application lifecycle management, task scheduling, and package management.

- **[AMS](ams.md)** — Activity Manager Service, application/Activity lifecycle management
- **[PMS](pms.md)** — Package Manager Service, application package management
